1. Git dan GitHub

Sekitar 40 menit. Hasil lomba dikumpulkan lewat GitHub, jadi ini wajib lancar.

Apa itu Git?

Bayangkan main game yang bisa save. Git menyimpan kodemu sebagai save point yang namanya commit. Kalau kodemu rusak, kamu tinggal kembali ke save sebelumnya. GitHub adalah tempat menaruh save-an itu di internet, seperti Google Drive khusus untuk kode.

Alur kerja empat langkah

Edit file → git add (pilih file yang mau disimpan) → git commit (simpan dengan catatan) → git push (kirim ke GitHub).

Atur identitas (sekali saja)

git config --global user.name "Nama Kamu"
git config --global user.email "emailgithub@contoh.com"

Membuat repository pertama

mkdir latihan-lks
cd latihan-lks
git init
echo "<?php echo 'Halo, UMKM!';" > halo.php
git status
git add .
git commit -m "Tambah halo.php"
git log --oneline

git status adalah perintah paling berguna: ia memberi tahu apa yang berubah. Biasakan menjalankannya sebelum add dan commit.

Menyiapkan SSH key

SSH key itu seperti kartu akses. Dengan kartu ini GitHub tahu bahwa yang mengirim kode benar-benar kamu. Di lomba, ini wajib disiapkan sebelum hari H.

ssh-keygen -t ed25519 -C "emailgithub@contoh.com"
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
cat ~/.ssh/id_ed25519.pub

Salin seluruh hasil perintah terakhir. Di GitHub buka Settings → SSH and GPG keys → New SSH key, lalu tempel. Uji dengan ssh -T git@github.com.

Mengirim ke GitHub

Buat repository kosong bernama latihan-lks di GitHub (tanpa README), lalu:

git remote add origin git@github.com:USERNAME/latihan-lks.git
git branch -M main
git push -u origin main

Setelah itu, setiap perubahan cukup: git add ., git commit -m "pesan", git push.

Aturan commit message: tulis apa yang berubah, misalnya "Tambah tabel usaha". Jangan "update" atau "asdf".

Di bawah ini ada terminal tiruan. Ketik perintahnya di kolom paling bawah, lalu tekan Enter. Tidak perlu membuka laptop. Bingung? Tekan tombol Petunjuk.

Kalau ada error

nothing to commit: kamu lupa menyimpan file di VS Code, atau lupa git add .

rejected / non-fast-forward: kamu membuat repo dengan README. Hapus repo lalu buat ulang tanpa README.

2. MySQL dan SQL

Sekitar 50 menit. 15% nilai lomba ada di desain database, dan semua fitur lain bergantung padanya.

Konsep

Bayangkan lemari arsip. Database adalah lemarinya, tabel adalah satu map di dalamnya, baris adalah satu lembar data, dan kolom adalah kolom isian di lembar itu (nama, omzet, dan seterusnya). Bahasa yang dipakai untuk memerintah database namanya SQL.

Nyalakan MySQL dari Laragon atau XAMPP, lalu buka terminal: mysql -u root (atau pakai phpMyAdmin).

Membuat database dan tabel

CREATE DATABASE modalin;
USE modalin;

CREATE TABLE usaha (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nama VARCHAR(100) NOT NULL,
  sektor VARCHAR(50),
  omzet_bulanan BIGINT NOT NULL
);
TipeUntuk
INT, BIGINTBilangan bulat (BIGINT untuk uang besar)
VARCHAR(n)Teks pendek, maksimal n karakter
TEXTTeks panjang
DATE, TIMESTAMPTanggal dan waktu

PRIMARY KEY adalah penanda unik tiap baris, seperti NIK. NOT NULL berarti wajib diisi.

Bedah kode baris per baris

CREATE DATABASE modalin; : buat database bernama modalin.

USE modalin; : mulai bekerja di database itu.

CREATE TABLE usaha ( : buat tabel bernama usaha. Isinya didaftar di dalam kurung.

id INT AUTO_INCREMENT PRIMARY KEY : kolom id, berisi bilangan bulat, nomornya naik sendiri (1, 2, 3), dan jadi pengenal unik.

nama VARCHAR(100) NOT NULL : kolom nama, teks maksimal 100 huruf, wajib diisi.

omzet_bulanan BIGINT NOT NULL : kolom omzet, bilangan bulat besar, wajib diisi.

Empat operasi dasar (CRUD)

-- Create
INSERT INTO usaha (nama, sektor, omzet_bulanan) VALUES
 ('Warung Makan Bu Sari', 'Kuliner', 12000000),
 ('Kopi Lereng Merapi', 'Kuliner', 30000000),
 ('Batik Tulis Giriloyo', 'Fesyen', 18000000);

-- Read
SELECT * FROM usaha;
SELECT nama, omzet_bulanan FROM usaha WHERE sektor = 'Kuliner' ORDER BY omzet_bulanan DESC;

-- Update
UPDATE usaha SET omzet_bulanan = 15000000 WHERE id = 1;

-- Delete
DELETE FROM usaha WHERE id = 3;
Awas: UPDATE dan DELETE tanpa WHERE mengubah atau menghapus semua baris. Tulis WHERE dulu sebelum yang lain.

Relasi antar tabel dan JOIN

Satu usaha bisa mengajukan banyak pinjaman. Supaya tahu pengajuan ini milik usaha yang mana, tiap pengajuan mencatat nomor usaha pemiliknya. Kolom pencatat nomor itulah foreign key, ibarat nomor ID tamu yang menunjuk ke tabel lain.

CREATE TABLE pengajuan (
  id INT AUTO_INCREMENT PRIMARY KEY,
  usaha_id INT NOT NULL,
  jumlah BIGINT NOT NULL,
  tenor INT NOT NULL,
  status VARCHAR(20) NOT NULL DEFAULT 'submitted',
  FOREIGN KEY (usaha_id) REFERENCES usaha(id)
);

INSERT INTO pengajuan (usaha_id, jumlah, tenor, status) VALUES
 (1, 25000000, 12, 'verified'),
 (2, 75000000, 24, 'submitted'),
 (1, 10000000, 6, 'rejected');

SELECT u.nama, p.jumlah, p.status
FROM pengajuan p
JOIN usaha u ON u.id = p.usaha_id;

JOIN menggabungkan dua tabel lewat kolom yang berhubungan. Huruf p dan u adalah nama singkat (alias) supaya penulisan lebih pendek.

Bedah kode baris per baris

SELECT u.nama, p.jumlah, p.status : tampilkan kolom nama dari tabel u, serta jumlah dan status dari tabel p.

FROM pengajuan p : data utamanya dari tabel pengajuan, kita singkat jadi p.

JOIN usaha u : gabungkan dengan tabel usaha, kita singkat jadi u.

ON u.id = p.usaha_id : sambungkan baris yang nomor id usahanya sama dengan usaha_id di pengajuan.

Menghitung: COUNT, SUM, GROUP BY

SELECT status, COUNT(*) AS banyak, SUM(jumlah) AS total
FROM pengajuan
GROUP BY status;

GROUP BY mengelompokkan baris yang statusnya sama, lalu COUNT dan SUM menghitung tiap kelompok.

Fungsi

Kode yang dipakai berulang dibungkus jadi fungsi, seperti resep: kamu beri bahan (parameter), lalu ia menyerahkan hasil (return).

<?php
function rupiah(int $angka): string
{
    return 'Rp' . number_format($angka, 0, ',', '.');
}

function plafon(int $omzetBulanan, int $kali = 3): int
{
    return $omzetBulanan * $kali;
}

echo rupiah(plafon(12000000)) . PHP_EOL;   // Rp36.000.000
Bedah kode baris per baris

function rupiah(int $angka): string : buat fungsi bernama rupiah. Ia menerima satu bilangan bulat ($angka) dan hasilnya berupa teks (string).

return 'Rp' . number_format(...) : tulis "Rp" lalu sambung (titik) dengan angka yang sudah diberi titik ribuan, lalu serahkan hasilnya.

int $omzetBulanan, int $kali = 3 : parameter kedua punya nilai awal 3. Kalau tidak diisi, otomatis dikali 3.

Kesalahan yang paling sering: lupa $ di depan variabel, lupa titik koma, memakai + untuk menggabung teks (yang benar .), dan lupa return.

4. PHP OOP dan dasar Laravel

Sekitar 60 menit. Laravel dibangun dengan OOP, jadi pahami idenya dulu.

OOP: cetakan kue

Sebuah class adalah cetakan kue. Kue hasil cetakannya disebut object. Data di dalam object disebut property, dan hal yang bisa dilakukannya disebut method. Method __construct jalan sendiri saat object dibuat.

<?php
class Pengajuan
{
    public function __construct(public int $jumlah, public int $tenor)
    {
    }

    public function cicilanPokok(): int
    {
        return intdiv($this->jumlah, $this->tenor);
    }
}

$p = new Pengajuan(12000000, 12);   // buat object dari cetakan
echo $p->cicilanPokok();            // 1000000
Bedah kode

new Pengajuan(12000000, 12) : cetak satu object, isi jumlah dan tenornya.

public int $jumlah di dalam kurung constructor : sekaligus membuat property jumlah dan mengisinya.

$this : object itu sendiri. $this->jumlah berarti "jumlah milik object ini".

$p->cicilanPokok() : panah -> artinya "buka isi object, jalankan method ini".

Latihan: lengkapi method

Apa itu Laravel?

Laravel adalah framework PHP, ibarat rangka rumah yang sudah jadi. Kamu tinggal mengisi ruangannya. Dua alat utamanya: Composer (pengunduh paket PHP) dan Artisan (asisten yang membuatkan file lewat perintah php artisan ...).

Alur kerja saat ada permintaan masuk: Route (alamat) → Controller (pengatur) → Model (penghubung ke database) → hasil dikirim kembali sebagai JSON.

app/Http/ControllersController

Migration: tabel lewat kode

Schema::create('pengajuans', function (Blueprint $table) {
    $table->id();
    $table->foreignId('usaha_id')->constrained();
    $table->unsignedBigInteger('jumlah');
    $table->unsignedSmallInteger('tenor');
    $table->string('status')->default('submitted');
    $table->timestamps();
});

foreignId('usaha_id')->constrained() membuat foreign key ke tabel usaha. timestamps() membuat kolom created_at dan updated_at otomatis.

class Pengajuan extends Model

// di PengajuanController

$fillable adalah daftar kolom yang boleh diisi lewat create(). Kalau lupa menulisnya, muncul error MassAssignmentException.

5. REST API

Sekitar 60 menit. 25% nilai lomba ada di REST API, bagian terbesar.

Apa itu API?

API adalah pintu layanan. Aplikasi lain (misalnya React) mengirim permintaan ke alamat tertentu, lalu server membalas dengan data berbentuk JSON. REST adalah aturan penamaan alamatnya: alamat = benda, jenis permintaan = aksi.

MethodAlamatAksi
GET/api/pengajuanLihat semua
POST/api/pengajuanBuat baru
GET/api/pengajuan/5Lihat satu
PUT/api/pengajuan/5Ubah
DELETE/api/pengajuan/5Hapus

Di routes/api.php, satu baris ini membuat kelimanya:

Route::apiResource('pengajuan', PengajuanController::class);

Format balasan JSON

Lomba meminta bentuk standar. Biasakan selalu begini:

{ "success": true, "message": "Pengajuan dibuat", "data": { "id": 1 } }
{ "success": false, "message": "Validasi gagal", "errors": { "jumlah": ["..."] } }

401Belum login
403Login tapi dilarang
404Tidak ditemukan

Validasi dengan Form Request

Aturan isian ditaruh di file tersendiri supaya controller tetap rapi.

class StorePengajuanRequest extends FormRequest
{
    public function authorize(): bool { return true; }

    public function rules(): array
    {
        return [
            'usaha_id' => 'required|exists:usahas,id',
            'jumlah'   => 'required|integer|min:5000000|max:50000000',
            'tenor'    => 'required|integer|in:6,12,24',
        ];
    }

    protected function failedValidation(Validator $v)
    {
        throw new HttpResponseException(response()->json([
            'success' => false, 'message' => 'Validasi gagal', 'errors' => $v->errors(),
        ], 422));
    }
}

// di controller
public function store(StorePengajuanRequest $request)
{
    $p = Pengajuan::create($request->validated());
    return response()->json(['success' => true, 'message' => 'Pengajuan dibuat', 'data' => $p], 201);
}
Bedah kode

required : wajib diisi. integer : harus bilangan bulat. min dan max : batas nilai.

exists:usahas,id : nilainya harus ada di kolom id tabel usahas (cek foreign key).

in:6,12,24 : hanya boleh salah satu dari ketiganya.

$request->validated() : hanya data yang lolos aturan, jadi aman dipakai.

Menguji dengan Postman

1. Pilih method (GET/POST), isi alamat http://127.0.0.1:8000/api/pengajuan.

2. Di tab Headers tambahkan Accept: application/json. Tanpa ini, error muncul sebagai halaman HTML.

3. Untuk POST, buka tab Body, pilih raw lalu JSON, dan isi datanya.

6. Keamanan: login, role, dan batas percobaan

Sekitar 60 menit. Ini 15% nilai lomba. Tiga hal yang diminta: token (Sanctum), RBAC (Policy), dan rate limiting.

Login dengan token (Sanctum)

Alurnya seperti tiket konser. Kamu login sekali, server memberi token (tiket). Untuk tiap permintaan berikutnya, kamu menunjukkan tiket itu lewat header Authorization: Bearer TOKEN.

// app/Models/User.php
use Laravel\Sanctum\HasApiTokens;
class User extends Authenticatable { use HasApiTokens; }

// AuthController
public function login(LoginRequest $request)
{
    $user = User::where('email', $request->email)->first();
    if (! $user || ! Hash::check($request->password, $user->password)) {
        return response()->json(['success' => false, 'message' => 'Email atau password salah'], 401);
    }
    $token = $user->createToken('api')->plainTextToken;
    return response()->json(['success' => true, 'message' => 'Login berhasil', 'data' => ['token' => $token]]);
}

public function logout(Request $request)
{
    $request->user()->currentAccessToken()->delete();
    return response()->json(['success' => true, 'message' => 'Logout berhasil']);
}

Hash::check membandingkan password yang diketik dengan versi terenkripsi di database. Password tidak pernah disimpan apa adanya.

Melindungi rute: bungkus dengan middleware auth:sanctum. Tanpa token, otomatis dibalas 401.

Route::post('/login', [AuthController::class, 'login']);

Route::middleware('auth:sanctum')->group(function () {
    Route::post('/logout', [AuthController::class, 'logout']);
    Route::apiResource('pengajuan', PengajuanController::class);
});

RBAC: hak akses per role

RBAC artinya hak akses ditentukan oleh role. Tambahkan kolom role di tabel users (umkm, staff, manager). Aturannya ditulis di Policy.

class PengajuanPolicy
{
    public function verify(User $user, Pengajuan $p): bool
    {
        return $user->role === 'staff' && $p->status === 'submitted';
    }
    public function approve(User $user, Pengajuan $p): bool
    {
        return $user->role === 'manager' && $p->status === 'verified';
    }
}

// di controller
$this->authorize('verify', $pengajuan);   // gagal otomatis jadi 403

Rate limiting

Fitur sensitif seperti login perlu dibatasi supaya password tidak bisa ditebak ribuan kali.

Route::post('/login', [AuthController::class, 'login'])->middleware('throttle:5,1');

throttle:5,1 artinya maksimal 5 percobaan per 1 menit. Percobaan ke-6 dibalas 429.

7. Database lanjutan: UUID, soft delete, audit log

Sekitar 50 menit. Bagian dari 15% nilai desain database.

UUID sebagai primary key

UUID adalah ID acak panjang, misalnya 9b2f6c1e-.... Berbeda dari 1, 2, 3, orang tidak bisa menebak data berikutnya.

// migration
$table->uuid('id')->primary();
$table->foreignUuid('usaha_id')->constrained();

// model
use Illuminate\Database\Eloquent\Concerns\HasUuids;
class Pengajuan extends Model { use HasUuids; }

Soft delete

Hapus data tapi tidak benar-benar menghilangkannya. Baris hanya diberi tanda waktu di kolom deleted_at, jadi bisa dipulihkan.

// migration
$table->softDeletes();

// model
use Illuminate\Database\Eloquent\SoftDeletes;
class Pengajuan extends Model { use HasUuids, SoftDeletes; }

$p->delete();                          // hanya diberi tanda
Pengajuan::withTrashed()->get();       // termasuk yang sudah "dihapus"
$p->restore();                         // pulihkan

Relasi antar model

// Usaha.php
public function pengajuans() { return $this->hasMany(Pengajuan::class); }
// Pengajuan.php
public function usaha() { return $this->belongsTo(Usaha::class); }

$p->usaha->nama;      // ambil nama usaha dari sebuah pengajuan

hasMany artinya "punya banyak". belongsTo artinya "milik satu". Keduanya memanfaatkan foreign key.

Audit log

Audit log adalah buku catatan: siapa mengubah apa dan kapan. Caranya, buat tabel audit_logs lalu catat otomatis lewat Observer, yaitu class yang bereaksi saat data dibuat, diubah, atau dihapus.

class PengajuanObserver
{
    public function updated(Pengajuan $p): void
    {
        AuditLog::create([
            'user_id'  => auth()->id(),
            'aksi'     => 'update',
            'model'    => 'Pengajuan',
            'model_id' => $p->id,
            'sebelum'  => json_encode($p->getOriginal()),
            'sesudah'  => json_encode($p->getChanges()),
        ]);
    }
}

// app/Providers/AppServiceProvider.php, di method boot()
Pengajuan::observe(PengajuanObserver::class);

Latihan: siapa boleh apa?

Aturan 3x omzet

Pinjaman tidak boleh lebih dari 3 kali omzet bulanan usaha. Cek di Form Request atau controller, dan kembalikan 422 kalau melanggar.

if ($request->jumlah > $usaha->omzet_bulanan * 3) {
    return response()->json(['success' => false, 'message' => 'Jumlah melebihi 3x omzet'], 422);
}

Cicilan anuitas (amortisasi)

Cicilan anuitas besarnya sama tiap bulan, tapi isinya berubah: awalnya banyak bunga, lama-lama banyak pokok. Rumusnya, dengan i = bunga per tahun / 12 / 100 dan n = tenor (bulan):

cicilan = pokok x i / (1 - (1 + i) ^ -n)

Tiap bulan: bunga = sisa pinjaman x i, porsi pokok = cicilan dikurangi bunga, lalu sisa pinjaman berkurang sebesar porsi pokok. Tabel semua bulan itu disebut jadwal amortisasi.

Bunga 0% membuat rumus membagi dengan nol. Tangani dulu: kalau bunga 0, cicilan = pokok / tenor.
